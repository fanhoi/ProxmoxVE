## 💽 Хранилище и сетевые ресурсы

### 🔍 Проверка состояния накопителей и SMART (`disk-health.sh`)

Скрипт для экспресс-диагностики физических накопителей (NVMe, SATA SSD, HDD). Формирует понятный русскоязычный отчёт по температуре, износу, ресурсу и критическим SMART-атрибутам, а также позволяет запустить безопасный фоновый тест самодиагностики.

#### ⚡ Команда для запуска (вставьте в консоль Proxmox VE):

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/fanhoi/ProxmoxVE/main/tools/disk-health.sh)"
```

#### ✨ Ключевые возможности:
- **Автопоиск накопителей**: находит физические диски, исключая loop, zram и виртуальные device-mapper разделы.
- **Поддержка NVMe**: температура, доступный резерв (Available Spare), процент износа (Percentage Used), объём записанных данных, время наработки, небезопасные отключения, ошибки целостности данных.
- **Поддержка SATA SSD и HDD**: температура, часы наработки, индикатор износа (Wear Leveling/Wearout), переназначенные секторы (Reallocated), нестабильные секторы (Pending), неисправимые ошибки (Offline Uncorrectable), ошибки передачи (UDMA CRC).
- **Самодиагностика**: запуск короткого фонового теста (**SHORT SMART Self-Test**) через удобное интерактивное меню.
- **Автоматика**: при отсутствии `smartmontools` или `nvme-cli` скрипт сам аккуратно установит недостающие пакеты.

### 🧹 Очистка осиротевших LVM-томов (`clean-orphaned-lvm.sh`)

Утилита для поиска и безопасного удаления неиспользуемых (осиротевших) логических LVM-томов, оставшихся в пулах LVM/LVM-Thin после удаления виртуальных машин или LXC-контейнеров.

#### ⚡ Команда для запуска (вставьте в консоль Proxmox VE):

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/fanhoi/ProxmoxVE/main/tools/clean-orphaned-lvm.sh)"
```

#### ✨ Ключевые возможности:
- **Умное сканирование**: сравнивает существующие тома `lvs` с конфигурациями виртуальных машин и контейнеров по всем нодам кластера Proxmox VE.
- **Защита системных данных**: автоматически исключает системные разделы (`root`, `data`, `swap`), OSD Ceph и служебные пулы `thin-pool`.
- **Интерактивное удаление**: отображает сводную таблицу с именами томов, группами (VG) и размером, запрашивая подтверждение перед удалением каждого найденного тома.

### 🌐 Мастер хранилищ и общих ресурсов (`storage-share-helper.sh`)

Универсальный интерактивный мастер для тестирования сетевых подключений, добавления и удаления сетевых хранилищ в Proxmox VE, проброса папок в LXC-контейнеры (bind mounts) и настройки общих папок на самом хосте.

#### ⚡ Команда для запуска (вставьте в консоль Proxmox VE):

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/fanhoi/ProxmoxVE/main/tools/storage-share-helper.sh)"
```

#### ✨ Ключевые возможности:
- **Диагностика и тестирование**: ручные тесты монтирования SMB/CIFS, экспорта NFS, поиск таргетов iSCSI (discovery), просмотр статуса хранилищ (`pvesm status`) и активных сессий.
- **Подключение хранилищ к Proxmox VE**: пошаговое добавление SMB/CIFS, NFS, iSCSI и LVM поверх базового iSCSI-таргета с выбором типов контента (ISO, бэкапы, образы дисков, шаблоны).
- **Точки монтирования LXC (Bind Mounts)**: добавление (`pct set -mpX`) и безопасное удаление точек монтирования между хостом и контейнерами с автопоиском свободных слотов.
- **Общие ресурсы на хосте PVE**: автоматическая установка и быстрая настройка сервера Samba (SMB) или NFS-экспорта непосредственно на хосте Proxmox.
- **Безопасное удаление**: удобный мультивыбор хранилищ и точек монтирования для удаления с защитой от случайного нажатия (по умолчанию выбор «Нет»).

## 💾 Резервное копирование и бэкапы

### 📦 Резервное копирование конфигураций хоста (`host-backup.sh`)

Интерактивный мастер для быстрого создания архивных копий (`tar.gz`) критически важных конфигураций хоста (например, `/etc/`, `/var/lib/pve-cluster/`, `/root/`) с выбором целевой папки для сохранения архива.

#### ⚡ Команда для запуска (вставьте в консоль Proxmox VE):

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/fanhoi/ProxmoxVE/main/tools/host-backup.sh)"
```

#### ✨ Ключевые возможности:
- **Гибкий выбор источников**: архивация всей директории целиком или выборочных подпапок и файлов через интерактивный чек-лист.
- **Настройка пути сохранения**: возможность сохранить бэкап локально (`/root/`) или сразу на примонтированное внешнее хранилище (`/mnt/pve/...`, `/mnt/backups/`).
- **Автоматическое именование**: создает имя архива с именем хоста, путем и отметкой времени ISO (`YYYY_MM_DDTHH_MM`).

## 🗑️ Управление гостевыми системами

### 🧹 Массовое удаление LXC-контейнеров и виртуальных машин (`guest-delete.sh`)

Интерактивная утилита для быстрого и безопасного пакетного удаления ненужных LXC-контейнеров и виртуальных машин (KVM/QEMU) с автоматической остановкой и очисткой неиспользуемых дисков.

#### ⚡ Команда для запуска (вставьте в консоль Proxmox VE):

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/fanhoi/ProxmoxVE/main/tools/guest-delete.sh)"
```

#### ✨ Ключевые возможности:
- **Удобный графический список**: наглядный чек-лист с ID, названиями и текущим статусом (running/stopped) всех контейнеров и виртуальных машин.
- **Опции пакетного выбора**: возможность быстро выбрать все LXC (`ALL-CT`) или все ВМ (`ALL-VM`).
- **Корректная остановка**: автоматически мягко останавливает запущенные контейнеры (`pct stop`) и ВМ (`qm stop`) перед удалением.
- **Полная очистка хранилища**: удаляет связанные непривязанные виртуальные диски (`--purge --destroy-unreferenced-disks`).
- **Два режима работы**: пошаговое подтверждение каждого объекта вручную (`m`) или автоматическое пакетное удаление (`a`).
